# Flappy Bird

这段提示词用于让 AI 一次性生成一个完整的 Flappy Bird 网页小游戏。玩家通过点击或按空格键控制小鸟扑翼上升，躲避不断向左移动的管道障碍，包含重力物理模拟、管道随机生成、得分统计和逐渐加速的难度递增机制，以及卡通风格的可爱界面，适合快速生成一个可直接在浏览器中运行的单文件 HTML 游戏。

## 提示词

```text
请用一个 HTML 文件实现一个完整的 Flappy Bird 网页小游戏，要求如下：

1. 使用原生 HTML + CSS + JavaScript，不依赖任何外部库，生成单个 HTML 文件即可在浏览器中运行。
2. 游戏区域使用 Canvas 绘制，居中显示，背景为渐变天空色，底部有地面。
3. 小鸟受重力影响持续下落，玩家点击屏幕或按空格键使小鸟向上扑翼跳跃。
4. 管道从右侧不断生成并向左移动，上下管道之间留有随机高度的间隙供小鸟通过。
5. 小鸟成功穿过一组管道得 1 分，得分显示在画面上方中央，使用大号字体。
6. 小鸟碰到管道或地面/天花板时游戏结束，小鸟有坠落动画。
7. 游戏结束后显示当前得分和历史最高分（使用 localStorage 持久化），并提供重新开始按钮。
8. 小鸟根据上升/下落状态有不同的旋转角度，管道使用绿色经典配色。
9. 支持电脑端（键盘/鼠标）和移动端（触屏点击）操作。
10. 整体界面采用卡通风格，色彩明快，小鸟和管道用简单的几何图形绘制即可。
```
