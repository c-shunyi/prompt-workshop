# 贪吃蛇

这段提示词用于让 AI 一次性生成一个完整的贪吃蛇网页小游戏。它涵盖了游戏的核心玩法（键盘控制蛇的移动方向、吃食物增长、碰墙或咬到自己则游戏结束）、得分统计、像素风格的界面样式，以及开始/重新开始等基本交互，适合快速生成一个可直接在浏览器中运行的单文件 HTML 游戏原型。

## 提示词

```text
请用一个 HTML 文件实现一个完整的贪吃蛇网页小游戏，要求如下：

1. 使用原生 HTML + CSS + JavaScript，不依赖任何外部库，生成单个 HTML 文件即可在浏览器中运行。
2. 游戏区域使用 Canvas 绘制，居中显示在页面上，背景为深色，蛇身和食物使用鲜明的对比色。
3. 玩家通过键盘方向键（↑↓←→）控制蛇的移动方向，蛇不能直接掉头（如正在向右移动时不能直接变为向左）。
4. 食物随机出现在游戏区域内，蛇吃到食物后身体增长一格，同时得分加 1。
5. 蛇撞到墙壁或自身时游戏结束，弹出"游戏结束"提示并显示最终得分。
6. 页面上方显示当前得分，提供一个"开始游戏"按钮，游戏结束后可点击按钮重新开始。
7. 整体界面采用像素风 / 复古游戏风格，简洁美观。
```
