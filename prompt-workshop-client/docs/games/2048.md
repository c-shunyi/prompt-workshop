# 2048

这段提示词用于让 AI 一次性生成一个完整的 2048 网页小游戏。玩家通过方向键滑动数字方块，相同数字碰撞后合并翻倍，目标是合成 2048。游戏包含平滑的滑动动画、得分统计，以及简洁现代的界面风格，适合快速生成一个可直接在浏览器中运行的单文件 HTML 游戏。

## 提示词

```text
请用一个 HTML 文件实现一个完整的 2048 网页小游戏，要求如下：

1. 使用原生 HTML + CSS + JavaScript，不依赖任何外部库，生成单个 HTML 文件即可在浏览器中运行。
2. 游戏区域为 4×4 的网格，居中显示在页面上，带有圆角和阴影效果。
3. 玩家通过键盘方向键（↑↓←→）滑动所有方块，同时支持触屏滑动操作。
4. 相同数字的方块碰撞后合并为两倍数值，每次滑动后在空位随机生成一个 2 或 4。
5. 不同数值的方块使用不同的背景色，数值越大颜色越深/越醒目。
6. 页面上方显示当前得分和最高分（使用 localStorage 持久化最高分）。
7. 当出现 2048 方块时弹出胜利提示，玩家可选择继续游戏。
8. 当所有格子填满且无法合并时游戏结束，显示最终得分。
9. 提供"新游戏"按钮可随时重新开始。
10. 整体界面风格参考原版 2048，简洁、现代、配色柔和。
```
