# 俄罗斯方块

这段提示词用于让 AI 一次性生成一个完整的俄罗斯方块网页小游戏。它涵盖了游戏的核心玩法（7 种经典方块的随机生成与旋转、左右移动与加速下落、满行消除与得分计算）、等级与速度递增机制、下一个方块预览，以及复古像素风的界面样式，适合快速生成一个可直接在浏览器中运行的单文件 HTML 游戏原型。

## 提示词

```text
请用一个 HTML 文件实现一个完整的俄罗斯方块网页小游戏，要求如下：

1. 使用原生 HTML + CSS + JavaScript，不依赖任何外部库，生成单个 HTML 文件即可在浏览器中运行。
2. 游戏区域使用 Canvas 绘制，标准 10 列 × 20 行的网格，居中显示在页面上，背景为深色并绘制网格线。
3. 包含全部 7 种经典方块（I、O、T、S、Z、L、J），每种方块使用不同的鲜明颜色。
4. 玩家通过键盘控制：←→ 左右移动，↑ 旋转方块，↓ 加速下落，空格键直接落到底部（硬降）。
5. 方块落到底部后自动锁定，检测并消除已填满的行，支持同时消除多行并给予额外加分。
6. 页面右侧显示当前得分、已消除行数、当前等级，以及下一个方块的预览。
7. 随着消除行数增加，等级提升，方块下落速度逐渐加快。
8. 当新方块无法放入游戏区域时游戏结束，显示"游戏结束"提示和最终得分。
9. 提供"开始游戏"按钮，游戏结束后可点击重新开始。
10. 整体界面采用像素风 / 复古游戏风格，简洁美观。
```
