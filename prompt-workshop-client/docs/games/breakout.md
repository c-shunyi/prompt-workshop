# 打砖块

这段提示词用于让 AI 一次性生成一个完整的打砖块网页小游戏。玩家控制底部挡板反弹小球，击碎上方排列的彩色砖块，包含不同颜色砖块的分值差异、多关卡递进、球速加快等经典机制，以及霓虹灯风格的炫酷界面，适合快速生成一个可直接在浏览器中运行的单文件 HTML 游戏。

## 提示词

```text
请用一个 HTML 文件实现一个完整的打砖块（Breakout）网页小游戏，要求如下：

1. 使用原生 HTML + CSS + JavaScript，不依赖任何外部库，生成单个 HTML 文件即可在浏览器中运行。
2. 游戏区域使用 Canvas 绘制，居中显示，深色背景。
3. 玩家通过鼠标移动（或键盘 ←→）控制底部的挡板左右滑动。
4. 小球从挡板弹出，碰到墙壁和砖块时反弹，碰到挡板时根据击中位置改变反弹角度。
5. 砖块排列为多行多列，不同行的砖块颜色不同，靠上方的砖块分值更高。
6. 小球落到底部（未被挡板接住）则失去一条命，共 3 条命，全部用完则游戏结束。
7. 所有砖块被击碎后进入下一关，下一关球速加快、砖块行数增加。
8. 页面上方显示当前得分、当前关卡、剩余生命数。
9. 提供"开始游戏"按钮，游戏结束后可重新开始。
10. 整体界面采用霓虹灯 / 赛博朋克风格，砖块和小球带有发光效果。
```
