# 扫雷

这段提示词用于让 AI 一次性生成一个完整的扫雷网页小游戏。它涵盖了经典扫雷的核心玩法（左键翻开格子、右键插旗标记、数字提示周围地雷数、空白区域自动展开）、三种难度选择、计时器与地雷计数器，以及经典 Windows 风格的界面，适合快速生成一个可直接在浏览器中运行的单文件 HTML 游戏。

## 提示词

```text
请用一个 HTML 文件实现一个完整的扫雷网页小游戏，要求如下：

1. 使用原生 HTML + CSS + JavaScript，不依赖任何外部库，生成单个 HTML 文件即可在浏览器中运行。
2. 提供三种难度：初级（9×9，10 个雷）、中级（16×16，40 个雷）、高级（30×16，99 个雷）。
3. 左键点击翻开格子：如果是地雷则游戏结束，如果是数字则显示周围 8 格中的地雷数量，如果是空白则自动递归展开相邻的空白区域。
4. 右键点击在未翻开的格子上插旗/取消插旗，用于标记疑似地雷的位置。
5. 第一次点击保证不会踩雷（动态调整地雷位置）。
6. 页面顶部显示剩余地雷数（总雷数减去已插旗数）和计时器（从第一次点击开始计时）。
7. 游戏结束时（踩雷或全部安全格翻开）显示所有地雷位置，踩到的雷标红。
8. 提供一个笑脸按钮，点击可重新开始当前难度的游戏。
9. 整体界面采用经典 Windows 扫雷风格，格子带有立体凸起/凹陷效果。
```
