# 文章分享平台数据库设计

> 本文档用于定义文章分享平台的核心数据结构，适用于基于 **MySQL 8.0 + Prisma** 的后端项目。设计目标是在满足文章发布、分类标签、点赞收藏等基础业务的同时，保持结构清晰、便于后续扩展管理台、通知系统、搜索系统与数据统计能力。

## 设计原则

- 使用 **MySQL** 作为主业务数据库
- ORM 使用 **Prisma**
- 所有主键统一使用 `Int` 自增
- 时间字段统一使用 `created_at`、`updated_at`
- 表名使用复数命名，字段名使用下划线命名
- 状态字段统一使用 `Int` 表示，便于管理台筛选和扩展
- 高并发统计字段采用冗余计数字段，减少频繁聚合查询

## 核心表清单

| 表名 | 说明 |
| --- | --- |
| `users` | 前台用户表 |
| `articles` | 文章表 |
| `categories` | 分类表 |
| `tags` | 标签表 |
| `article_tags` | 文章和标签关系表 |
| `article_likes` | 文章点赞表 |
| `article_favorites` | 文章收藏表 |

## 表结构设计

### 1. users

用于存储平台注册用户信息。

| 字段名 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `id` | `Int` | PK, AI | 用户 ID |
| `username` | `VarChar(50)` | UNIQUE, NOT NULL | 用户名 |
| `email` | `VarChar(100)` | UNIQUE, NOT NULL | 邮箱 |
| `password_hash` | `VarChar(255)` | NOT NULL | 密码哈希 |
| `nickname` | `VarChar(50)` | NULL | 昵称 |
| `avatar` | `VarChar(255)` | NULL | 头像地址 |
| `bio` | `VarChar(255)` | NULL | 个人简介 |
| `status` | `Int` | DEFAULT 1 | 状态，`1` 正常，`0` 禁用 |
| `last_login_at` | `DateTime` | NULL | 最后登录时间 |
| `created_at` | `DateTime` | NOT NULL | 创建时间 |
| `updated_at` | `DateTime` | NOT NULL | 更新时间 |

索引建议：

- `UNIQUE(username)`
- `UNIQUE(email)`
- `INDEX(status)`

### 2. articles

用于存储文章主体内容。

| 字段名 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `id` | `Int` | PK, AI | 文章 ID |
| `user_id` | `Int` | FK, NOT NULL | 作者 ID，关联 `users.id` |
| `category_id` | `Int` | FK, NULL | 分类 ID，关联 `categories.id` |
| `title` | `VarChar(255)` | NOT NULL | 文章标题 |
| `summary` | `VarChar(500)` | NULL | 文章摘要 |
| `content` | `LongText` | NOT NULL | 文章正文 |
| `status` | `Int` | DEFAULT 0 | 状态，`0` 草稿，`1` 已发布，`2` 下架 |
| `view_count` | `Int` | DEFAULT 0 | 浏览量 |
| `like_count` | `Int` | DEFAULT 0 | 点赞数 |
| `favorite_count` | `Int` | DEFAULT 0 | 收藏数 |
| `published_at` | `DateTime` | NULL | 发布时间 |
| `created_at` | `DateTime` | NOT NULL | 创建时间 |
| `updated_at` | `DateTime` | NOT NULL | 更新时间 |

索引建议：

- `INDEX(user_id)`
- `INDEX(category_id)`
- `INDEX(status)`
- `INDEX(published_at)`
- `INDEX(status, published_at)`

### 3. categories

用于文章分类管理。

| 字段名 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `id` | `Int` | PK, AI | 分类 ID |
| `name` | `VarChar(50)` | UNIQUE, NOT NULL | 分类名称 |
| `slug` | `VarChar(50)` | UNIQUE, NOT NULL | 分类英文标识 |
| `sort` | `Int` | DEFAULT 0 | 排序值 |
| `status` | `Int` | DEFAULT 1 | 状态，`1` 启用，`0` 禁用 |
| `created_at` | `DateTime` | NOT NULL | 创建时间 |
| `updated_at` | `DateTime` | NOT NULL | 更新时间 |

### 4. tags

用于文章标签管理。

| 字段名 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `id` | `Int` | PK, AI | 标签 ID |
| `name` | `VarChar(50)` | UNIQUE, NOT NULL | 标签名称 |
| `created_at` | `DateTime` | NOT NULL | 创建时间 |
| `updated_at` | `DateTime` | NOT NULL | 更新时间 |

### 5. article_tags

用于建立文章与标签的多对多关系。

| 字段名 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `id` | `Int` | PK, AI | 主键 |
| `article_id` | `Int` | FK, NOT NULL | 文章 ID，关联 `articles.id` |
| `tag_id` | `Int` | FK, NOT NULL | 标签 ID，关联 `tags.id` |
| `created_at` | `DateTime` | NOT NULL | 创建时间 |

约束与索引建议：

- `UNIQUE(article_id, tag_id)`
- `INDEX(tag_id)`

### 6. article_likes

用于记录用户对文章的点赞行为。

| 字段名 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `id` | `Int` | PK, AI | 主键 |
| `article_id` | `Int` | FK, NOT NULL | 文章 ID |
| `user_id` | `Int` | FK, NOT NULL | 用户 ID |
| `created_at` | `DateTime` | NOT NULL | 点赞时间 |

约束与索引建议：

- `UNIQUE(article_id, user_id)`
- `INDEX(user_id)`

### 7. article_favorites

用于记录用户收藏文章的行为。

| 字段名 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `id` | `Int` | PK, AI | 主键 |
| `article_id` | `Int` | FK, NOT NULL | 文章 ID |
| `user_id` | `Int` | FK, NOT NULL | 用户 ID |
| `created_at` | `DateTime` | NOT NULL | 收藏时间 |

约束与索引建议：

- `UNIQUE(article_id, user_id)`
- `INDEX(user_id)`

## 表关系说明

- 一个用户可以发布多篇文章，`users 1 - n articles`
- 一个分类下可以有多篇文章，`categories 1 - n articles`
- 一篇文章可以绑定多个标签，一个标签也可属于多篇文章，`articles n - n tags`
- 用户可对文章点赞和收藏，分别通过 `article_likes`、`article_favorites` 建立多对多关系

## MVP 最小可用版本

如果当前目标是尽快完成一个可上线演示的 MVP，建议先落这 8 张表：

- `users`
- `articles`
- `categories`
- `tags`
- `article_tags`
- `article_likes`
- `article_favorites`

这一版已经足够支撑以下能力：

- 用户注册登录
- 文章发布与编辑
- 分类与标签
- 点赞与收藏

当前阶段暂不包含文件上传能力，因此不设计独立的上传文件表。后续如果需要支持正文图片或附件，再补充 `uploads` 或对象存储映射表即可。

## Prisma 建模建议

为了和当前项目风格保持一致，建议 Prisma 层采用以下约定：

- 模型名使用 PascalCase，例如 `User`、`Article`
- 数据表使用 `@@map("table_name")`
- 时间字段使用 `@map("created_at")`、`@map("updated_at")`
- 自增主键统一使用 `@id @default(autoincrement())`
- 多对多中间表显式建模，便于后续扩展字段
